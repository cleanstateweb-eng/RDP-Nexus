## RDP Nexus 1.0.9

**Install:** download **`RDPNexus-setup.exe`** below and double-click it: it installs with no questions,
closes and replaces a running older version, keeps your settings and starts RDP Nexus.

### New
- **The installer always installs the newest version.** While it installs, any RDP Nexus installer
  (from this version on — even one downloaded long ago) checks GitHub for the newest release. If
  there is a newer one, it downloads it, verifies its SHA-256 checksum and installs that instead; the
  progress bar shows the download. Offline, you get the version the installer contains.
- **No downgrades.** If a newer version is already installed, an older installer changes nothing
  (it only hands over to an even newer release, if GitHub has one) and leaves a running RDP Nexus
  alone.

### Fixed
- If RDP Nexus's program folder had been removed while Windows still listed it under **Apps**, the
  installer now simply installs it again.
