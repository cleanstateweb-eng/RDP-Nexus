## RDP Nexus 1.0.5

**Install:** download **`RDPNexus-setup.exe`** below and double-click it (per-user, no admin rights;
upgrades 1.0.x in place and keeps your settings).

### New
- **Background mode** (on by default): selecting the RDP window is enough. RDP Nexus keeps the session
  active while you use other apps, with the RDP window behind other windows, minimized or on another
  virtual desktop. Input is sent straight to the RDP window, so your local apps, keyboard focus and
  mouse pointer are never touched, and the window is never brought to the front. The status shows
  **Running in background**. Turn it off in **Options → Background** to get the 1.0.4 behaviour.
- **You no longer have to keep the mouse over the RDP window.** Your own pointer is only moved while it
  rests over the active RDP window; anywhere else only the remote pointer moves.
- **Test now** works with the RDP window in the background: keep it visible and press the button.
- Scroll option **Mouse wheel**, and scrolling waits until the switched-to app has appeared.
- About shows a link to this repository.

### Fixed
- A hand-edited `settings.json` containing `Infinity` stopped the app from starting.
- Documentation now states exactly when Alt+Tab is sent (only to an active, full-screen or
  "On the remote computer" RDP window; never in background mode).

### Note
Background mode sends input to the RDP window without it being the active window. Microsoft doesn't
document this for Remote Desktop clients, and it has not yet been confirmed on every client. If nothing
happens with the RDP window in the background, nothing is sent anywhere else: turn off
**Options → Background**.
